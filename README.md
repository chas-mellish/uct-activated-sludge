# UCT Activated Sludge Model

## Overview
Conversion of legacy Pascal code for the University of Cape Town (UCT) activated sludge model.

## Project Structure
- `legacy/pascal/` - Original Pascal source code
- `docs/UCT_Design_Manual/` - Reference documentation and theory papers
- `docs/ASM1/` - Activated Sludge Model 1 manual reference documentation to simulate activated sludge processes
- `src/` - New implementation code
- `converted/` - Morph-converted intermediate files

## History
Originally written in Pascal for 5-point titration calculations.
Currently being converted using Morph for modern compilation.
